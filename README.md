# Prácticas de Sistemas Operativos

Repositorio con las prácticas de laboratorio del curso. Cada práctica vive en su propia carpeta, con su propio `README.md` con instrucciones específicas.

## Prácticas

| Carpeta | Contenido |
|---|---|
| [lab-01](lab-01/README.md) | Exploración de Windows y sus recursos mediante comandos de PowerShell. |
| [lab-02](lab-02/README.md) | Anatomía de los comandos de PowerShell: prompt, comando, opciones y argumentos. |
| [lab-03](lab-03/README.md) | Análisis de un catálogo de películas IMDb con PowerShell y generación de reportes. |
| [lab-04](lab-04/automatizacion_ps1_toppeliculas.md) | Automatización de reportes de películas mediante un script `.ps1` parametrizado. |
| [lab-05](lab-05/README.md) | Instalación de VirtualBox y Ubuntu en Windows o macOS. |
| [lab-06](lab-06/README.md) | Uso de Docker Desktop para descargar, configurar y ejecutar un contenedor nginx. |
| [lab-07](lab-07/README.md) | Sistemas de archivos del anfitrión, Docker y contenedores usando la terminal. |
| [lab-07-b](lab-07-b/README.md) | Alternativa de la práctica de Docker en GitHub Codespaces. |
| [lab-08](lab-08/README.md) | Administración de sistemas de archivos y permisos de acceso en un servidor Linux con Docker. |

## Cómo usar este repositorio
1. Entra a la carpeta de la práctica que te corresponda.
2. Lee el `README.md` de esa carpeta: ahí están el objetivo, los requisitos y las instrucciones de entrega.
3. Sigue la guía paso a paso incluida en la carpeta.
4. Entrega el archivo indicado en el `README.md` de esa práctica, a través de la plataforma del curso.

## Cómo se agregan nuevas prácticas
Cada práctica nueva se agrega como una carpeta independiente (`practica-02-...`, `practica-03-...`), con su propio `README.md`, y se enlista en la tabla de arriba.
